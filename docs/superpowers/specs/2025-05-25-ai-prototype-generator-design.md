# AI 文档→原型生成器 设计文档

## 背景

将现有 AI 代码生成平台从「前端网页搭建助手」重新定位为「AI 文档→原型生成器」。

**现有痛点：** "AI 生成网站"定位太泛，面试官觉得 v0.dev / Cursor 能替代，项目缺乏差异化。

**新痛点：** PM 写完 PRD 后要等设计师 2-3 天出 Figma 原型，再等前端切页面。中间等待是产品研发流程最大的瓶颈。AI 直接从 PRD 生成可交互原型，跳过中间环节，将周期缩短至分钟级。

## 目标用户

产品经理。写完 PRD 后粘贴到平台，快速生成可交互原型供团队评审。

## 输入

Markdown 格式的 PRD 文档。用户在前端文本框中粘贴 Markdown 内容。

## 输出

AI 智能路由根据文档复杂度自动选择生成策略：

| 策略 | 适用场景 | 输出 |
|------|---------|------|
| HTML | 单页面简单原型 | 一个 index.html |
| MULTI_FILE | 多区块原型 | index.html + style.css + script.js |
| VUE_PROJECT | 复杂多页面应用 | 完整 Vue 项目（路由、组件、布局） |

原型交互程度：页面间可点击跳转，表单可输入，按钮有点击反馈。

## 工作流

用户粘贴 PRD → AI 解析文档结构 → 智能路由选策略 → Agent 工作流执行（素材采集 → Prompt 增强 → 代码生成 → 质量检查 → 构建）→ 生成可交互原型 → 一键部署为可访问链接。

## 改动范围

### 不变的组件（后端引擎）

- LangGraph 工作流（节点、边、条件分支）
- 代码生成引擎（HTML/MultiFile/Vue 三种模式）
- Tool Calling（文件操作、图片搜索、Logo 生成）
- 智能路由服务
- 质量检查 + 输出护轨（自动重试）
- SSE 流式输出
- 一键部署 + COS 截图
- 用户认证、限流、聊天历史

### 需要改动的组件

| 组件 | 改动内容 | 工作量 |
|------|---------|--------|
| Prompt 词 | codegen-html / codegen-multi-file / codegen-vue-project 三个提示词从「生成网站」改为「根据 PRD 生成可交互原型」| 小 |
| 前端 UI | 入口从「输入一句话」改为「粘贴 PRD 文档（Markdown）」，文本框加大，支持 Markdown 预览 | 中 |
| 前端文案 | 简介、标题、引导文案全部更新 | 小 |
| README | 更新项目描述 | 小 |

**结论：后端引擎零改动，改动集中在 Prompt 和前端展示层。换皮级别改造。**

## 简历描述

### 项目标题

AI 文档→原型生成器

### 项目描述

基于 LangChain4j + LangGraph4j 的 AI 原型生成平台。产品经理粘贴 PRD 需求文档，AI Agent 自动解析文档结构并执行素材搜集、代码生成、质量检查、项目构建的完整工作流，生成可交互的多页面 HTML 原型，一键部署为可访问链接供团队快速评审，将需求到原型的周期从 2-3 天缩短至分钟级。

### 技术栈

LangChain4j + LangGraph4j + Spring Boot 3 + MyBatis Flex + COS + Redis + Nginx

### 职责描述

1. AI 原型生成服务：利用 LangChain4j 框架集成 DeepSeek、通义等多种大模型，根据 PRD 文档自动分析页面结构、功能模块和交互流程，生成可交互的多页面原型。
2. Prompt 调优：针对 PRD 解析、页面规划、代码生成等不同阶段设计专用提示词，通过结构化输出和少样本示例提升文档理解准确率。
3. 智能路由：利用 LangChain4j 结构化输出特性，根据文档复杂度自动选择 HTML / 多文件 / Vue 项目三种生成策略，平衡成本与质量。
4. Agent 工作流编排：基于 LangGraph4j 构建多步骤 Agent 工作流，实现素材采集→代码生成→质量检查→项目构建的自动化流水线，支持条件分支和循环重试。
5. 对话历史查询：基于时间游标分页实现对话历史查询，避免深分页性能问题，复合索引优化查询性能 3 倍。
6. 安全与质量保障：基于输入护轨进行 Prompt 安全审查（敏感词/注入检测），基于输出护轨对 AI 生成代码进行质量校验并自动触发重试。
7. 项目部署上线：利用 1Panel + Docker 在 Linux 服务器部署，Nginx 反向代理解决跨域问题。
